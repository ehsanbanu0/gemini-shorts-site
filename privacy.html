Privacy Policy

Last updated: October 20, 2026

This policy describes the personal project Gemini Shorts Automation.

Information and services used

The project may read publicly available trending-topic information, send selected topic and script-generation prompts to the Google Gemini API, generate narration using a text-to-speech service, and upload videos and related metadata to the owner's YouTube channel using the YouTube Data API.

Account access and credentials

Google OAuth credentials and API keys are intended to be stored as private GitHub Actions secrets, not in the public website repository. The project uses YouTube authorization only to perform the configured upload workflow. The owner can revoke access from their Google Account security settings.

Website visitors

This static website does not provide forms or intentionally collect personal information from visitors. GitHub may process standard technical logs when serving the site under its own policies.

Third-party services

Google, YouTube, GitHub, and any text-to-speech provider process information according to their own terms and privacy policies. Data sent to these services is subject to their practices.

Retention and changes

Generated scripts and videos may be retained in the project owner's automation artifacts or YouTube account. This policy may be updated if the project's behavior changes.

Contact

For questions about this personal project, contact the project owner through the GitHub repository.
