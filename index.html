Gemini Shorts Automation

This is a personal software project that experiments with drafting short educational videos from publicly available trending-topic feeds and publishing them to a connected YouTube channel.

The project uses Google Gemini to help draft scripts, text-to-speech to create narration, and the YouTube Data API to upload videos when the owner runs or schedules the workflow.

This is an independent personal project and is not affiliated with or endorsed by Google or YouTube.
